# Mettelo Business Analyst Project Studio

## MTL-BA-044 — Employee Onboarding & Access Management Transformation

An end-to-end simulated business change engagement for Business Analysts. You have joined Harrowgate Professional Services Ltd as the BA. New starters arrive without equipment or appropriate access, while some leavers retain access. Teams use separate forms and queues. The sponsor wants one onboarding portal, but ownership and authoritative dates are disputed.

Start with [Project brief](project/PROJECT_BRIEF.md), [Delivery guide](project/DELIVERY_GUIDE.md) and [Release manifest](project/RELEASE_MANIFEST.csv).

All organisations, people, case records, quotes, policies and pilot results are synthetic unless explicitly labelled external reference. This is simulated experience; describe it accurately in your portfolio. No real personal data, production credentials or live transactions belong here.

## Progressive discovery

This public repository is the complete facilitator source library. GitHub folders and branches do not enforce secrecy. For an authentic cohort, the facilitator distributes only the paths assigned to the current release in a separate private learner space. Self-directed learners should open releases in order and record their decisions before continuing.

The five releases cover initiation; elicitation; operational analysis; disruption; and delivery assurance/benefits review. Later pilot evidence describes a disputed supplier experiment, not an approved answer. Your recommendation may reject it.

## Source formats

Forms are editable Markdown and working registers are CSV for accessibility and version review; these replace the PDF/XLSX filenames in the planning conversation without supplying completed BA outputs. Read the evidence dictionary before calculating measures.

## Repository guide

business_context: sponsor and organisation sources. stakeholders: role descriptions and interviews, without an influence matrix. evidence: operational extracts and correspondence. policies: existing fictional rules. systems: current capabilities and constraints. reference: external provenance. change_scenarios: staged sponsor events. project: participant instructions. submission: submission guidance only.

No completed process maps, requirements catalogues, stakeholder matrices, user stories or model solutions are supplied.
