# Current systems

PeopleRecord holds approved dates and employment status. Daily 06:00 UK CSV feeds ServiceQueue. Directory handles core identity. Several client SaaS tools have separate access administration. Facilities uses a restricted workbook for passes and desks. CourierDesk records dispatch and delivery separately.
ServiceQueue closure currently accepts a dispatch reference and directory-created event. No employee sign-in validation is required. HR date corrections do not reopen a closed ticket automatically.
